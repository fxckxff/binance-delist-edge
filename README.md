# Binance delisting edge

Исследование шорта после анонса делистинга Binance и монитор новостей без отправки ордеров.

**Текущий вывод: устойчивое преимущество после расходов и фактической задержки исполнения не доказано.** Исходные утверждения о точном пороге 30 секунд и недоступности стратегии через любой бесплатный канал были слишком категоричными. Обнаруженные ошибки и исправления: [AUDIT.md](AUDIT.md).

## Запуск

Python 3.10+, единственная прямая зависимость — httpx.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python selftest_monitor.py
.venv/bin/python audit_research.py
.venv/bin/python build_manifest.py
```

`audit_research.py` работает без сети: проверяет согласованность сохранённых данных и пересчитывает минутную сетку в `data/audit_v2.json`.

```bash
# Тиковый пересчёт из публичного архива Binance:
.venv/bin/python tick_backtest.py
# Пробный прогон: отдельный *.v2.sample.json, основной отчёт не перезаписывает:
.venv/bin/python tick_backtest.py --limit 5
# Минутные данные из API:
.venv/bin/python backtest_futures.py --pages 9
# Необязательные живые проверки монитора:
.venv/bin/python selftest_monitor.py --live
```

Новые отчёты имеют суффикс `.v2.json`; неполные тиковые прогоны — `.v2.partial.json`. Исторические JSON и таблицы сохранены для сравнения, но не являются результатами исправленного кода. Точный статус воспроизведения: [VERIFICATION.md](VERIFICATION.md).

## Монитор

```bash
.venv/bin/python monitor.py
# В другом терминале, из папки проекта:
touch STOP
# Перед следующим запуском удалить STOP.
```

По умолчанию состояние и логи находятся в папке проекта: `state/`, `logs/bot.log`, `logs/observations.jsonl`. `NEWS_ROOT` меняет корень. Доступны `NEWS_POLL_INTERVAL` (15 секунд), `NEWS_STALE_AFTER` (900 секунд), `NEWS_MIN_DEPTH_USD` (5000 USD по bids). Невалидные числовые настройки вызывают ошибку.

Первый запуск запоминает текущую ленту без сигналов. `SIGNAL PAPER` — наблюдение, **не бумажная сделка**. Детали: [PROTECTIONS.md](PROTECTIONS.md). Монитор не устанавливается в автозапуск этой командой.

## Модель и ограничения

- Исторический манифест: 115 символов-событий, 74 timestamp публикации. Он сохраняется для сопоставимости, не считается доказанно полным.
- Тиковый вход — первая сделка после задержки; выход по горизонту — первая сделка на/после deadline; стоп — наблюдаемая цена пробоя. Это ценовая модель без стакана и исполнения объёма.
- Минутный расчёт использует только закрытые свечи и отклоняет неполные горизонты. Горизонт отсчитывается от публикации, а не входа.
- Условный портфель: одна позиция за раз, пересечения пропускаются, одновременные кандидаты упорядочены по символу. Это явное исследовательское правило, не найденная оптимальная стратегия.
- Бутстрэп группирует токены одной публикации. Поправки на множественный подбор, независимой будущей выборки, funding и точной модели ликвидации нет.
- Скрипты `analyze_edge.py`, `split_by_type.py`, `report_*.py` и прежние таблицы — вспомогательное историческое исследование; они не заменяют отчёты версии 2.
- `backtest_delist.py` признан недействительным и по умолчанию не запускается. Ключ `--allow-invalid-legacy` предназначен только для воспроизведения старой ошибки.

## Будущая выборка

Подготовлен [фиксированный протокол v1](FORWARD_PROTOCOL.md). Рядом с монитором запустите `.venv/bin/python forward_study.py collect`; отчёт — `.venv/bin/python forward_study.py report`. Сборщик сохраняет стаканы и гипотетические исполнения в SQLite. Это отдельный предварительный эксперимент с фиксированными правилами; `SIGNAL PAPER` самого монитора по-прежнему остаётся только сообщением.
