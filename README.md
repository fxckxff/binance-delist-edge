# Binance delisting edge — независимо воспроизводимое исследование

Вопрос, на который отвечает проект: **можно ли устойчиво зарабатывать, шортя
токены в момент анонса их делистинга с Binance, начиная с $1 000?**

Короткий ответ: **нет — при нашем (и любом бесплатном) лаге обнаружения.**
Эдж существует, но он чисто скоростной и умирает за ~30 секунд, а бесплатный
канал Binance отдаёт анонс с задержкой 55–130 секунд. См. `VERIFICATION.md`
с точными числами и командами воспроизведения.

Цель этого репозитория — чтобы **любой человек** мог пересчитать все выводы
сам, из первоисточников, не доверяя ни одному закоммиченному числу.

## Что здесь лежит

### Воспроизводимые измерения эджа
| Файл | Что считает | Первоисточник |
|---|---|---|
| `tick_backtest.py` | затухание эджа по лагу (тики) | data.binance.vision |
| `backtest_futures.py` | сетка лаг×стоп×горизонт на 1m фьючерсах | Binance fapi |
| `horizon_test.py` | медленные горизонты до 7 дней | Binance fapi |
| `analyze_edge.py` | распределение сделок, концентрация прибыли | кэш 1m |
| `split_by_type.py` | деление по типу анонса | CMS + кэш 1m |
| `tg_lag.py` | лаг Telegram против CMS | t.me архив |
| `lead_lag.py` | кто раньше: Bybit или Binance | Bybit API + CMS |

### Замеры инфраструктуры (специфичны для региона/времени)
| Файл | Что измеряет |
|---|---|
| `probe_ratelimit.py` | лимит запросов к CMS |
| `probe_ttl*.py` | TTL кэша CloudFront, заголовок `age` |
| `probe_ttl_variants.py` | TTL разных вариантов URL |

### Живой монитор (НЕ торгует)
`monitor.py` + `monitor_core.py` — слушатель анонсов. Пишет в лог
`SIGNAL PAPER` и `detect_lag`. **Ордеров не отправляет ни реальных, ни бумажных.**
Защиты описаны в `PROTECTIONS.md`, тесты — `selftest_monitor.py`.

## Запуск

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# главный воспроизводимый прогон (тики, ~115 архивов, ~10 мин):
python tick_backtest.py

# сетка на 1m фьючерсах:
python backtest_futures.py --pages 9
```

Python 3.10+. Единственная зависимость — `httpx`.

## Статус депозита

Реальные деньги **не использовались и не рекомендованы**. Монитор работает
в бумажном режиме. Ни одна сумма доходности здесь не является обещанием:
цифра «+$101 016» в тиковом отчёте — артефакт компаундинга, см. `VERIFICATION.md`.

## Данные

Большие сырые кэши (тики, 1m на 7 дней) в git не входят — они перекачиваются
скриптами из первоисточников. Закоммичены компактные входы и результаты:
`data/events.json` (манифест 115 событий), `data/cms_articles.json`,
`data/*_backtest.json`, `data/tg_lag.json`, `data/lead_lag.json`, зонды.
